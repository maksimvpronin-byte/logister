## Применение к работающему окружению

Рабочий API заменён проверенным бинарным файлом. Предыдущий бинарный файл
сохранён локально в `api/bin/logister-api-before-ingest-fixes-20261103`.

Генератор временно приостанавливался на границе завершённой строки. Перед
заменой отправщика последняя строка была найдена в поиске, а счётчики прочитанных
и успешно отправленных записей совпали.

Новая база позиций однократно инициализирована в режиме чтения с конца файла.
При остановленном отправщике проверено, что сохранённый offset равен размеру
полностью доставленного файла: 131551 байт. Затем восстановлено чтение новых
файлов с начала, отправщик перезапущен с тем же томом, генератор возобновлён.
Новые логи принимаются с HTTP 202; PostgreSQL и OpenSearch доступны.

## Оставшиеся границы

Пачка не является транзакцией OpenSearch. При потерянном подтверждении записи
исход отдельного элемента может быть неизвестен; повтор всей пачки всё ещё
может создать дубли. Идемпотентность HTTP-приёма, аварийные отключения, все
варианты ротации файлов и заполнение диска этим изменением не закрыты.

Остальные замечания A04–A10 исходного аудита остаются открытыми.
